# Security

This is an experimental open-source repository and is not a production support promise. No supported production version, response-time guarantee, bounty, certification, or broad disclosure policy is implied by this document.

## Please do not disclose sensitive details publicly

Do not put secrets, credentials, tokens, exploit details, private telemetry, or personal/device/location data in a public issue, pull request, commit, or discussion. Do not upload sensitive logs or proof-of-concept material until a private reporting channel has been established.

The public `fR3kdev/fR3k` repository is separate from private FR3K research and control-plane material. Do not disclose or copy private research, execution records, infrastructure details, or other non-public material into this repository.

## Reporting a vulnerability

1. If GitHub's private vulnerability reporting option is available for this repository, use that private channel and include the minimum information needed for triage.
2. If no private reporting option is available, open a minimal public issue titled `Security contact request` with no vulnerability details, exploit code, secrets, or sensitive attachments. We can use that request to establish a safer private communication path.

When a private channel is available, please include where safe:

- affected component and version or commit;
- security impact and likely conditions;
- a minimal reproduction or clear steps to reproduce;
- relevant logs or evidence with secrets and private identifiers removed;
- a suggested mitigation or workaround, if known.

Please avoid public disclosure until the issue has been privately discussed. This repository does not promise a particular response time or coordinated-disclosure outcome.
