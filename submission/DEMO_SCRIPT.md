**0:00–0:15 — Hook**  
A real livestream failure became the demo. fR3k is an agent that acts across apps, then proves each action happened.

**0:15–0:30 — Mission**  
Show the path: YouTube → GitHub → ntfy → GitHub evidence. Explain that each app has a necessary role.

**0:30–0:45 — Runtime**  
Show the execution loop and typed-tool contract. Stress that state is grounded before mutation.

**0:45–1:00 — Live reads**  
Show the actual GitHub issue and the verified YouTube live state.

**1:00–1:15 — Approval gate**  
Show that the ntfy write pauses for exact approval. No approval, no write.

**1:15–1:32 — Reliability event**  
Explain the real ntfy visibility race. The system refused to resend, then reconciled the existing receipt exactly once.

**1:32–1:47 — Evidence + evaluator**  
Show the GitHub evidence receipt and final evaluator: CONFIRMED_SUCCESS, 1.00, 7/7.

**1:47–1:58 — Close**  
77 tests, green CI, public receipts, open source. The point is not better agent theatre; it is safe external action with evidence.
