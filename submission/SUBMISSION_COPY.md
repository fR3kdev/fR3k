# Submission Copy

## Project name
**fR3k Agentic Action Engine**

## One-liner
A multi-app agent runtime that does not merely call tools: it policy-gates consequential actions, verifies external state after every write, and leaves replayable evidence.

## What it does
The live mission connects YouTube, GitHub and ntfy in one coherent workflow. It verifies the current livestream, grounds the task against a canonical GitHub issue, pauses before external writes, sends an approved operator notification, reconciles the exact receipt, writes verified evidence back to GitHub, and independently evaluates the trajectory.

## Why it is different
The system is designed around the ugly part of real agents: partial failure. A real provider-visibility race happened during the live run. fR3k refused to repeat the ambiguous write, reconciled it later without duplication, and converted that incident into a regression test.
